# ملخص سريع — الواجهة الخلفية لمنصة أمان

منصة «أمان» هي monorepo يضم ثلاثة تطبيقات (Laravel API، لوحة تحكم React، موقع Next.js) تشترك في واجهة برمجية واحدة هي المصدر الوحيد للحقيقة.
الواجهة الخلفية Laravel 11 بهيكل مبسّط: لا `Http/Kernel.php` ولا `routes/api.php` — كل التوجيه والوسائط والاستثناءات في `bootstrap/app.php`، والمنطق في `app/Services`.
جوهر النطاق تعليمي: فيديوهات مترجَمة بأعمدة JSON، أسئلة وتقدّم لكل متدرّب في `user_videos`، وشهادة PDF + QR تُولَّد عند اكتمال التقدّم والتقييم.

## نظرة عامة والتقنيات والبنية والتوجيه

**ما هو:** منصة «أمان» — monorepo بثلاثة تطبيقات وواجهة برمجية واحدة هي المصدر الوحيد للحقيقة (مصادقة، صلاحيات، ترجمة، شهادات، تقارير).

| المجلد | التقنية | المنفذ |
|---|---|---|
| `backend/` | Laravel 11 (v11.55) + Vite لأصول Blade فقط | 8000 |
| `dashboard/` | Vite + React 19 + TS | 5173 |
| `website/` | Next.js 16 | 3000 |

**التقنيات:** PHP ^8.2. حِزم مفتاحية: `sanctum` (رموز حاملة)، `spatie/laravel-permission`، `spatie/laravel-translatable` (أعمدة JSON ⇒ غير قابلة للترتيب)، `maatwebsite/excel`، `laravel-dompdf`، `bacon-qr-code`، `telescope` على مسار `tel513462`. هيكل Laravel 11 المبسّط: لا `Http/Kernel.php` ولا `Exceptions/Handler.php` — كله في `bootstrap/app.php`. و`app/Helpers/general.php` مُحمَّل عالميًا عبر `files`.

**البنية:** `app/{Http,Models,Services,Jobs,Mail,Enums,Exports,Helpers}`. القاعدة: **المنطق في `Services`** لا في المتحكمات (`AuthService`، `CertificateService`، `FailedValidation`، خدمات OTP والمخططات). مهمّة واحدة فقط: `Jobs/GenerateCertificate` (تحتاج عامل queue وإلا لا شهادة).

**التوجيه — الأهم:** **لا يوجد `routes/api.php`**. كل المسارات تُعرَّف داخل الإغلاق `then:` في `withRouting()`:

| البادئة | الملف | الوسائط بالترتيب |
|---|---|---|
| — | `web.php` | `ApiLocalization`, `web`, `RequestRateMiddleware` |
| `guest` | `guest.php` | `ApiLocalization`, `RequestRate` |
| `admin` | `admin.php` | `ApiLocalization`, `auth:sanctum`, `AdminMiddleware`, `RequestRate` |
| `user` | `user.php` | `ApiLocalization`, `auth:sanctum`, `UserMiddleware`, `RequestRate` |

لا `alias()` للوسائط ⇒ تُستخدم بالاسم الكامل (FQCN). `web.php` فيه `/`، `/up`، والمسار **العام** `storage/certificates/{pdf}` (`guest.storage.certificate`).

**الوسائط:** `ApiLocalization` تقرأ `Accept-Language` (أول عنصر + الوسم الأساسي) وتتحقق مقابل `['en','ar']`، وتضيف `Content-Language`، ولها أثر جانبي: `update(['lang'])` لكل طلب مُصادَق. `Admin/UserMiddleware` تُرجعان **400** (لا 401/403) ⇒ منطق الخروج التلقائي في الواجهات لا يُفعَّل. `RequestRateMiddleware` **ليست rate limiter** بل سجل تدقيق يخزّن كامل الجسم والترويسات (تسريب كلمات مرور/OTP/رموز + INSERT لكل طلب).

**الاستثناءات:** معالجان لطلبات JSON فقط: 401 `Unauthorized`، 404 `EndPoint Is Not Found`. أخطاء التحقق من `FailedValidation` بشكل `{message, errors:{field:[…]}}` — عقد `handleFormError` في الواجهتين.

**سؤال متوقع:** أين تُعرَّف المسارات ولماذا لا يجدي البحث في `routes/api.php`؟ لأنها كلها في الإغلاق `then:` داخل `bootstrap/app.php` موزّعة على `web/guest/admin/user.php`، و`api.php` غير موجود أصلًا.

## قاعدة البيانات والموديلات والعلاقات

**الأساس:** المخطط يُبنى بـ migrations في `database/migrations`؛ الحالة النهائية لأي جدول = ملف الإنشاء + كل التعديلات اللاحقة (مثال: `videos` أُنشئ 2024 ثم عُدّل في 6 ملفات). معظم الجداول soft-delete (`deleted_at`).

**المحور:** `videos` (المحتوى) ← `user_videos` (تسجيل المتدرّب ومساره) ← `user_answers` (إجاباته)، مع `questions` و`scenes` و`rates` و`tawias` معلّقة على `videos`.

| الجدول | أهم الأعمدة | العلاقات/FK |
|---|---|---|
| `users` | `mobile`+`otp` (دخول بلا كلمة مرور)، `full_name` **virtualAs**، `certificate_count` | لا FK |
| `videos` | `slug` unique، `video_url`/`description` json مترجم، `status`→`VideoStatus` | مصدر لكل التوابع |
| `questions` | `answers_a..d`, `wrong_a..d`, `correct_answer` enum, `appears_at` | FK → `videos` cascade |
| `user_videos` | `hearts`, `progress`, `is_rated`, `status` enum, حقول الشهادة | FK → users/videos |
| `user_answers` | `user_answer`, `status` | 4 FKs (فيها تكرار متعمّد لـ user_id/video_id) |

**الترجمة:** لا جدول ترجمة؛ العمود نفسه json `{"ar":..,"en":..}` + `$translatable` مع `spatie/laravel-translatable`، واللغة من ترويسة `Accept-language`. نتيجة مهمة: **لا `ORDER BY` على هذه الأعمدة**، والحل عملي في `Video::scenes()`/`questions()` بـ `STR_TO_DATE(JSON_EXTRACT(start_time,'$."{locale}"'),'%H:%i:%s')`.

**نمطان مقابلان للغة:** `blogs` = سجل واحد بأعمدة JSON مترجمة (محتوى تحريري)، `stories` = عمود `locale` وسجل لكل لغة (محتوى مستخدم).

**Traits وأنماط:** `IsActiveTrait` («نشِط» = غير محذوف)، `HasSlugTrait` (slug من الترجمة الإنجليزية + `withTrashed()` لتجنّب تعارض unique)، `LogoTrait` (accessor يبني `asset('storage/..')`). `Video::resolveIdFromRouteParameter` يجعل المسارات تقبل slug أو id. الحالة المشتقّة لا تُخزَّن: `Contact::status` accessor + `Contact::STATUS_SQL`. المشروع يستخدم `hasOne` بمفاتيح معكوسة بدل `belongsTo`، و`UserVideo::answers()` مقيّدة بـ `Auth::id()` فلا تصلح خارج سياق مستخدم.

**أهلية الشهادة** (`scopeIsApplicableForCertificate` + `certificateProgressPhases()`): `status=Accepted` و`progress>=99` و`is_rated=1` واكتمال بيانات المستخدم ← توليد `certificate_number/qr/url`.

**مصائد:** `user_videos.last_question_id` و`notifications.user_id` لا يوجد لهما FK فعليًا (`->on()` بلا `references()`، و`constrained()` مع `bigInteger`). `VideoStatus::Pending='New'`. جداول الدفع (`transactions`, `coupons`, `user_infos`, `news`) حُذفت في تمّوز 2026. `UserFactory` قديم وعدة factories فارغة.

**سؤال متوقع:** لماذا لا يمكن الترتيب على `videos.title`؟ لأنه عمود JSON مترجم، فالترتيب يحتاج استخراج مفتاح اللغة داخل تعبير SQL صريح.

## المصادقة والصلاحيات

**ما هو:** طبقة تحدّد *من* يصل إلى الـ API (Sanctum Bearer Tokens) و*ماذا* يفعل (spatie/laravel-permission).

### أربعة أبواب (معرَّفة في `bootstrap/app.php`، لا وجود لـ `routes/api.php`)

| البادئة | سلسلة Middleware | الجمهور |
|---|---|---|
| `guest/*` | `ApiLocalization` → `RequestRateMiddleware` | زوّار |
| `admin/*` | `ApiLocalization` → `auth:sanctum` → `AdminMiddleware` → `RequestRate` | لوحة التحكم |
| `user/*` | نفسه مع `UserMiddleware` | الموقع |

الترتيب مقصود: اللغة تُضبط قبل المصادقة، و`auth:sanctum` يصادِق الحامل ثم يميّز الـ middleware نوعه عبر `tokenable_type`. كلاهما يُرجع **400** بدل 403 (دلالة خاطئة).

### الحرّاس (`config/auth.php`)

`web`=session/User، `admin`=sanctum/`Admin`، `user`=sanctum/`User`. و`defaults.passwords = admins` قيمة معطوبة (لا وسيط بهذا الاسم) — لكن المشروع بنى تدفّق OTP الخاص به.

### الرموز

`$item->createToken("auth_token")->plainTextToken` في كل موضع: بلا abilities → `["*"]`، و`sanctum.expiration = null` → **رموز أبدية كاملة الصلاحية**. تسجيل الخروج (`HomeController::logout`) يحذف الرمز الحالي فقط، وإعادة تعيين كلمة المرور لا تُبطل القديم.

### التدفّقات

- أدمن: دخول بكلمة مرور (`AdminAuthController::loginRegisterResendOtp` — لا يرسل OTP رغم اسمه)، `requestOtp` → `SendEmailOTPService` (بريد)، `otpVerify`، `updatePassword` (تُسجّل الدخول تلقائيًا).
- مستخدم: `UserAuthController` + `SendUserOTPService` (SMS عبر msegat). التسجيل والدخول نقطة واحدة: أي رقم غير موجود يُنشأ تلقائيًا.
- صلاحية OTP 600 ثانية مكرّرة يدويًا في كل Request؛ `otpDelay = 0` أي لا كبح محاولات.

### الصلاحيات: تزيينية

- `Admin` يستخدم `HasRoles`؛ `User` لا. **لا يُنشأ أي role**؛ الصلاحيات تُربط مباشرة بـ `$admin->permissions()->sync(...)`، و`role_name` نصّ حرّ لا علاقة له بـ Spatie.
- البحث عن `can:` / `permission:` / `authorize(` في `routes/` و`Controllers/` = **صفر**. تُقرأ فقط عبر `AdminResource::getPermissionNames()` لإخفاء عناصر الواجهة → أي أدمن مصادَق ينادي أي مسار `admin/*`.

### الطبقة المشتركة

`BaseApiController::sendResponse` → مظروف `{status, message, data, guard, errors, response_code, request_body}`؛ `CustomFormRequest::authorize()` يُرجع `true` دائمًا، و`FailedValidation` تُنتج 422 بالشكل الذي يعتمده `handleFormError` في الواجهتين.

### أخطر العيوب

`guest/user/loginRegisterResendOtp` مربوط بـ `loginRegister` (بلا OTP) → رمز كامل لأي رقم جوال؛ `RequestRateMiddleware` يخزّن كل جسم وترويسات الطلب (كلمات مرور وtokens)؛ `withoutVerifying()` مع مزوّد SMS؛ `mobile_verified_at` غير fillable فيُسقَط صامتًا.

**سؤال متوقع:** هل إخفاء زرّ في اللوحة حسب الصلاحيات حماية؟ لا — لا يوجد فرض على الخادم، فنداء المسار مباشرة ينجح.

## واجهات الـ API

**ما هو:** طبقة REST واحدة في الـ backend تخدم الموقع ولوحة التحكم، مقسّمة **حسب الجمهور** لا حسب المورد.

**لماذا:** لا يوجد `routes/api.php` إطلاقًا؛ بمجرّد رؤية بادئة المسار تعرف الحرس والوسائط دون قراءة التعريف.

### التركيب (`backend/bootstrap/app.php`)

| البادئة | الملف | الوسائط |
|---|---|---|
| `guest/` | `routes/guest.php` | `ApiLocalization`, `RequestRateMiddleware` |
| `user/` | `routes/user.php` | + `auth:sanctum`, `UserMiddleware` |
| `admin/` | `routes/admin.php` | + `auth:sanctum`, `AdminMiddleware` |

- `ApiLocalization`: يقرأ `Accept-Language`، يضبط اللغة، ويحفظ `lang` على المستخدم.
- `RequestRateMiddleware`: **لا يحدّ المعدّل**؛ يسجّل كل طلب في جدول `RequestRate`.
- CSRF مُعطّل كليًا (`*`) — API برموز لا بجلسات.
- `spatie/laravel-permission` مُثبّتة لكن **بلا وسيط صلاحيات ولا `can:`**، و`CustomFormRequest::authorize()` تُعيد `true`. التخويل على مستوى الحرس فقط: أي مدير مُصادق يصل لكل نقطة إدارية.

### الغلاف الموحّد

`BaseApiController::sendResponse($status,$data,$message,$errors,$code,$request)` ⇒ `{status, local, message, data, guard, errors, response_code, request_body}`.
أخطاء التحقق (422) من `app/Services/FailedValidation` بغلاف مختلف: `request_data` بدل `request_body`، وبلا `local`.

### القوائم — `IndexTrait::indexInit`

منطق واحد لكل `index`: `per_page` (افتراضي 20)، `page`، `sort_column/sort_direction`، `date_from/date_to`، بحث حر `q`، فلترة ضمنية على `$fillable`، و`is_active`. القواعد في `config/constants.php`. مع `export=1` يتغيّر الشكل كليًا: XLSX عبر `maatwebsite/excel` ⇒ `data:{export,url}`.
الحمولة: `{helpers, items:{data,links,meta}}`. و`$deleted_at = auth('admin')->check()` ⇒ المدير يرى المحذوف ناعمًا.

### أبرز التدفّقات

- **مصادقة**: `guest/user/loginRegisterWithResendOtp` (يرسل OTP) ثم `otpVerify` ⇒ `{token,item}`؛ صلاحية OTP 600 ثانية. المدير بكلمة مرور + مسار OTP منفصل.
- **الشهادة**: عند `progress ≥ 99%` في `checkQuestionAnswer` يُضبط `certificate_number='CERT'.id` وتُطلَق وظيفة `GenerateCertificate` (QR + PDF + بريد).

### مخالفات لازمة الحفظ

رفض الحرس ⇒ **400**، صف خارج النطاق ⇒ **403**، تبعيات تمنع حذف فيديو ⇒ **429**، `statistics` الناجحة ⇒ **201**. ومسارا الشهادات (`.../pdf`, `pdf/fix`) يُرجعان **نصًّا خامًّا** بلا مصادقة ولهما آثار جانبية.

**سؤال متوقع:** هل تحمي `spatie/laravel-permission` نقاط النهاية الإدارية؟ لا — الصلاحيات بيانات لإخفاء عناصر الواجهة فقط، والحماية الفعلية هي حرس `admin` وحده.

## منطق العمل والميزات

### الكيان المحوري
`UserVideo` يجمع (التحاق + تقدّم + درجة + هوية شهادة) في صفّ واحد. حوله: `Video` (البرنامج، ورابط الفيديو نفسه مُترجَم)، `Scene`, `Question`, `UserAnswer`, `Rate`, `Tawia`.

- الترتيب: `start_time` / `appears_at` أعمدة JSON مُترجَمة، فيُستخرَج وقت اللغة الحالية بـ `JSON_EXTRACT` + `STR_TO_DATE` داخل `orderByRaw` — **MySQL فقط** (يفشل على sqlite).
- `Question::$attributes` تحمل قيمة JSON افتراضية لأن MySQL 8 لا يسمح بـ default لعمود JSON.
- الالتحاق **مجاني**: `status = Accepted` مباشرة، `hearts = 5`، ويُنشأ تلقائيًا عند أول فتح.
- `scopeCanonicalFor` يحلّ تعدّد صفوف الالتحاق: `CASE WHEN progress>=99 THEN 0 ELSE 1` ثم `latest()` — أي تفضيل المُنجَز ثم الأحدث (أصلح علّة إعادة المستخدم لبداية البرنامج).

### الإجابة على سؤال (`checkQuestionAnswer`)
قلب ±1 في المجال [0,5] (واجهة فقط) ← درجة ← `progress` محسوب على **عدد الأجوبة** لا الأسئلة المميّزة ← `answer_average` عبر `calculateAverageTime()` ← نقطة استئناف (`current_time`, `last_question_id`) تُصفَّر عند التجاوز.

### الشهادة
شرطان: `progress >= 99` **و** `is_rated == 1` (`isApplicableForCertificate`).

| المكوّن | التفصيل |
|---|---|
| الهوية | `certificate_number = 'CERT'.$id` بالضبط في `UserVideoController` و`RateController` (وإلا ملفات يتيمة) |
| البيئة | `CertificateService`: `assertAbsoluteUrl()` يرمي استثناء إذا `PLATFORM` فارغ/نسبي؛ `PLATFORM_CERT` لجلب اللوحة من `127.0.0.1:3000` |
| الـ PDF | `dompdf` (`enable_remote`) يطبع **صورة واحدة** فقط؛ لا نصّ |
| العربية | تُرسم في `website/src/app/api/certificate/[id]/route.ts` بـ node-canvas؛ **لا تشكيل مسبق** (Pango/HarfBuzz)، وحُذفت `shapeText` التي كانت تقلب الأسماء |
| QR | `BaconQrCode` → `qr/{cert}.png`، ويجب أن يُكتب **قبل** البريد لأن الرسالة تجلبه من التخزين |
| المتانة | مُتماثِلة (idempotent)؛ `is_certificate_generated=1` لا يُرفع إلا بعد تأكيد `storePdf()`+`exists()` |
| العرض للزائر | `notfound-display.php` **PHP خالص لا Blade** لتجنّب الكتابة في `storage/framework/views` |
| المراحل | `certificateProgressPhases()` بخمس مراحل + `current_phase` |

### الإحصاء والتصدير والمهام
- أربع خدمات رسوم (`UserGraph`, `GeneralGraph`, `ReportCertificateGraph`, `ReportUserGraph`): الـ constructor ينفّذ كل العمل والمصفوفات العامّة هي حِمل JSON. الفرق الدلالي: الأولى تعدّ الشهادات المُولَّدة فعلًا، الأخرى تعدّ الالتحاقات ودلو `0` لمن لا شهادة له.
- Excel: مُصدِّر عام `CollectionExport` عبر `?export=true` في `IndexTrait` — **متزامن تمامًا** رغم حقل الحالة في `Downloads`؛ خُطّاف `AfterSheet` يُدخل صفّ «Average» ويكتب التقييم كنصّ. `columnFormats()` يتعطّل بعد العمود `Z`.
- `GenerateCertificate` **لا يطبّق `ShouldQueue`**؛ يُستدعى بـ `dispatch()->afterResponse()` فينفّذ داخل PHP-FPM، بديلًا عن `Http::get()` الذي كان يفشل بـ DNS/cURL-28. البريد كذلك متزامن.

**سؤال متوقع:** هل تعمل الشهادة على queue worker؟ — لا، تُنفَّذ داخل عملية PHP نفسها بعد إرسال الاستجابة عبر `afterResponse()`.

## التعريب وملاحظات تقنية

**الهدف:** اللغة جزء من الطلب لا من حالة الخادم — العميل يرسل `Accept-Language`، والخادم يضبط الـ locale في بداية الدورة.

### ثلاث طبقات ترجمة
| الطبقة | المكان |
|---|---|
| رسائل النظام | `lang/en.json` / `lang/ar.json` — `trans('Listed')` |
| قواميس PHP | `lang/{ar,en}/*.php` (validation, certificate, map_countries) — `trans('msg.key')` |
| محتوى DB | أعمدة JSON عبر `spatie/laravel-translatable` |

- وجود اصطلاحين (`trans('key')` و `trans('msg.key')`) = دَين تقني.
- **عدم تزامن:** 121 مفتاحًا بالإنجليزية مقابل 109 بالعربية (12 مفقود). عند الغياب يعيد Laravel المفتاح نفسه كنص.

### الوسيط `ApiLocalization`
`app/Http/Middleware/API/ApiLocalization.php` — أول وسيط في المجموعات الأربع. يأخذ أول مقطع قبل الفاصلة، يحذف المنطقة (`en-US`→`en`)، يصغّر الأحرف، ويتحقق من `config('app.supported_languages') = ['en','ar']`؛ وإلا يعود إلى `app.locale`. ثم يضيف `Content-Language`.
**أثر جانبي:** إن كان الطلب موثّقًا ينفّذ `auth()->user()->update(['lang' => $locale])` في **كل** طلب — كتابة DB زائدة؛ الأنظف مقارنة القيمة قبل التحديث.

### الأعمدة المترجَمة
ستة موديلات بـ `HasTranslations`: `Blog`, `Faq`, `Question`, `Scenes`, `Tawia`, `Video`. لافت: `Video.video_url` مترجَم أيضًا (رابط فيديو لكل لغة).
**الفخ:** الترتيب في `IndexTrait::indexInit()` مبني على قائمة بيضاء (`id` + `$this->columns` + `$sortAllowed`) ويُتحقق بـ `in:` — فالترتيب على عمود مترجَم يعيد **422** من طبقة التحقق لا خطأ SQL.

### التخزين
أقراص `local` / `public` / `s3`، الافتراضي `local`. أربع دوال رفع غير متسقة في `app/Helpers/general.php`: `upload()`/`upload64()` (متطابقتان، تكتبان في `public_path` وتتجاوزان `Storage`)، `uploadToStorage()` (قرص public — لكنها تُعيد `response()->json` عند الفشل بدل استثناء)، `uploadStorage()` (قرص local تحت مجلد باسم `public`).

### ملاحظات حرجة
- **لا يوجد rate limiting** إطلاقًا: لا `throttle:` ولا `RateLimiter::for()`. و`RequestRateMiddleware` مُضلِّل الاسم — يسجّل كل طلب مع **كامل الجسم والترويسات** في `request_rates` (تسريب كلمات مرور ورموز Bearer + كتابة على كل طلب).
- **Telescope:** مُفعّل افتراضيًا، مساره المُبهم `tel513462` (أمان بالإخفاء لا بديل عن المصادقة). إلحاق `Telescope\Authorize` بمجموعة `web` كاملة سبّب **403 للزوّار** على `storage/certificates/{pdf}`.
- **`PLATFORM=` الفارغ:** `env()` تعيد الافتراضي فقط عند غياب المفتاح تمامًا — فالقيمة الفارغة تنتج `''` ⇒ روابط نسبية ⇒ PDF فارغ. العلاج: `assertAbsoluteUrl()` في `CertificateService` ترمي `RuntimeException` تذكر `PLATFORM`.
- `AdminMiddleware`/`UserMiddleware` يعيدان **400** لا 403 — انحراف دلالي لكنه عقد قائم مع الواجهتين.
- معالجات `bootstrap/app.php` (401/404) تعمل فقط عند `expectsJson()`.

**سؤال متوقع:** لماذا يعيد الترتيب على `title` رمز 422؟ لأن القائمة البيضاء في `indexInit()` ترفضه في طبقة التحقق قبل الوصول إلى قاعدة البيانات.

## أهم 15 نقطة يجب حفظها

1. لا يوجد `routes/api.php`؛ كل التوجيه في الإغلاق `then:` داخل `bootstrap/app.php` موزّعًا على `web/guest/admin/user.php`.
2. التقسيم حسب الجمهور لا حسب المورد: `guest/*` و`admin/*` و`user/*`، ولكل بادئة سلسلة وسائط ثابتة معروفة.
3. `ApiLocalization` أول وسيط دائمًا: يضبط اللغة قبل المصادقة ويكتب `lang` على المستخدم في كل طلب مُصادَق.
4. `RequestRateMiddleware` ليست rate limiter بل سجل تدقيق يخزّن كامل الجسم والترويسات — تسريب كلمات مرور وOTP ورموز Bearer.
5. لا rate limiting في المشروع إطلاقًا: لا `throttle:` ولا `RateLimiter::for()`.
6. رموز Sanctum بلا abilities (`["*"]`) وبلا انتهاء (`expiration = null`) ⇒ رموز أبدية كاملة الصلاحية.
7. الصلاحيات تزيينية: صفر `can:`/`permission:`/`authorize(` ⇒ أي أدمن مُصادَق يصل لأي مسار `admin/*`.
8. `AdminMiddleware`/`UserMiddleware` يعيدان **400** لا 401/403 ⇒ الخروج التلقائي في الواجهات لا يُفعَّل.
9. الترجمة بأعمدة JSON عبر `spatie/laravel-translatable` ⇒ لا `ORDER BY` عليها، والترتيب عليها يعيد **422** من القائمة البيضاء في `indexInit()`.
10. `orderByRaw` مع `JSON_EXTRACT` + `STR_TO_DATE` لترتيب `start_time`/`appears_at` ⇒ **MySQL فقط**، يفشل على sqlite.
11. `UserVideo` هو الكيان المحوري (التحاق + تقدّم + درجة + هوية شهادة)، والالتحاق مجاني وتلقائي بـ `Accepted` و`hearts=5`.
12. أهلية الشهادة: `progress >= 99` **و** `is_rated == 1`، والهوية `certificate_number = 'CERT'.$id` بالضبط في موضعين.
13. `GenerateCertificate` لا يطبّق `ShouldQueue`؛ يعمل بـ `dispatch()->afterResponse()` داخل PHP-FPM، والبريد متزامن أيضًا.
14. `PLATFORM` الفارغ ينتج روابط نسبية وPDF فارغًا؛ `assertAbsoluteUrl()` في `CertificateService` ترمي `RuntimeException`.
15. مظروف الاستجابة واحد (`BaseApiController::sendResponse`) لكن أخطاء 422 من `FailedValidation` بغلاف مختلف (`request_data` بلا `local`).

## أسئلة مناقشة سريعة

1. **أين تُعرَّف المسارات؟** داخل الإغلاق `then:` في `withRouting()` في `bootstrap/app.php`، لا في `routes/api.php` (غير موجود).
2. **لماذا تُستخدم الوسائط بأسمائها الكاملة (FQCN)؟** لأن المشروع لا يعرّف أي `alias()` للوسائط.
3. **هل تحمي `spatie/laravel-permission` نقاط النهاية الإدارية؟** لا — الصلاحيات بيانات لإخفاء عناصر الواجهة، والحماية الفعلية حرس `admin` فقط.
4. **لماذا لا يمكن الترتيب على `videos.title`؟** لأنه عمود JSON مترجم، والقائمة البيضاء ترفضه فيعيد 422 قبل الوصول إلى SQL.
5. **كيف تُحلّ مشكلة ترتيب المشاهد والأسئلة زمنيًا؟** باستخراج وقت اللغة الحالية بـ `JSON_EXTRACT` + `STR_TO_DATE` داخل `orderByRaw`.
6. **ما الفرق بين `blogs` و`stories` في التعريب؟** `blogs` سجل واحد بأعمدة JSON مترجمة، و`stories` سجل لكل لغة بعمود `locale`.
7. **هل تعمل الشهادة على queue worker؟** لا — تُنفَّذ في عملية PHP نفسها بعد إرسال الاستجابة عبر `afterResponse()`.
8. **ما أخطر عيب في تدفّق دخول المستخدم؟** `guest/user/loginRegisterResendOtp` مربوط بـ `loginRegister` بلا OTP ⇒ رمز كامل لأي رقم جوال.
9. **لماذا `notfound-display.php` بـ PHP خالص لا Blade؟** لتجنّب الكتابة في `storage/framework/views` عند العرض للزائر.
10. **ماذا يعني رمز 429 عند حذف فيديو؟** ليس كبح معدّل بل وجود تبعيات تمنع الحذف — انحراف دلالي مقصود ومحفوظ.
11. **لماذا ظهر 403 للزوّار على `storage/certificates/{pdf}`؟** لأن `Telescope\Authorize` أُلحق بمجموعة `web` كاملة فغطّى المسار العام.
12. **أين يقع منطق العمل؟** في `app/Services` (مثل `AuthService`, `CertificateService`, `FailedValidation`) لا في المتحكمات.
